# RozkladX — розклад КАІ ТЕХ

Статичний сайт (без сервера) — можна викласти на GitHub Pages як є.

## Що вміє
- **Вибір групи**: усі 60 груп коледжу. Для груп із записаним розкладом (★) — повний розклад;
  для решти — заміни з розпоряджень і посилання на офіційний PDF.
- **Живий час**: годинник і час пар у часовому поясі пристрою. Пари записані за Києвом; якщо телефон
  в іншому поясі (напр. Варшава), час пар перераховується автоматично. Пояс можна вибрати вручну (⚙️ → Інше).
- **Робочі суботи**: по колу ПН I → … → ПТ II; окремо для 1 курсу і для 2–4 курсів. Якщо в розпорядженні
  коледжу написано, за який день субота, — береться звідти. Кожну суботу можна виправити вручну.
- **Заміни/розпорядження**: автоматично з «Заміни.xlsx» на Google Drive коледжу (кожні 10 хв).
- **Тривога**: статус для вибраної області кожні 30 с, сирена, сповіщення.
- **Мікшер звуків** і **6 стилів**: Неон, Кіберпанк, Термінал, Синтвейв, Світлий, OLED.

## Як додати розклад групи
У `js/data.js` → `schedules` скопіюйте блок `'П-42'`, перейменуйте ключ на назву групи
точно як у списку `groups` (напр. `'К-42'`) і заповніть `subjects` та `schedule`.

## Перевірка
Час завжди береться з годинника пристрою. Тривогу можна перевірити кнопкою ⚙️ → Тривоги → «Тест тривоги».

## Публікація на GitHub Pages
Створіть репозиторій, завантажте всі файли, Settings → Pages → Deploy from branch → `main` / root.

## Оновлення сайту
Після змін збільште версію в `index.html` (тег `app-version` і `?v=` біля файлів css/js) — інакше браузери
можуть узяти старі файли з кешу. Відкриті вкладки самі перезавантажаться протягом 5 хв.
