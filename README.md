# RozkladX — розклад КАІ ТЕХ

Статичний сайт на GitHub Pages: https://rozkladx.github.io/ — без сервера й без бази даних.

## Звідки дані
| Що | Джерело | Як оновлюється |
|---|---|---|
| Розклади всіх груп | PDF на сторінці «Розклад занять» сайту коледжу | GitHub Actions щодня розбирає PDF → `data/schedules.json` |
| Заміни, розпорядження, робочі суботи | «Заміни.xlsx» на Google Drive коледжу | сайт читає напряму кожні 10 хв; Actions кожні 30 хв веде архів у `data/orders.json` |
| Повітряні тривоги | `ubilling.net.ua/aerialalerts` через `r.jina.ai` | сайт опитує кожні 30 с |
| Посилання на онлайн-пари | `js/data.js` → `links.lessons` | вручну (у PDF їх немає) |

## Як додати посилання на пари
У `js/data.js` → `links.lessons` додайте групу (назва як у списку на сайті, напр. `'К-33, К-30'`)
і пари `'Прізвище викладача': 'посилання'`. Якщо в одного викладача різні посилання на різні предмети —
ключ `'Прізвище|Початок назви предмета'`.

## Робот оновлення
`.github/workflows/update-data.yml` запускає `tools/build-data.mjs`:
- `node tools/build-data.mjs` — розклади + архів замін;
- `node tools/build-data.mjs --only-orders` — лише архів замін.

Запустити вручну: вкладка **Actions** → «Оновлення розкладів і замін» → **Run workflow**.
Якщо PDF якоїсь групи не вдалося прочитати, лишається попередня версія, а на сайті з'являється попередження.

## Що вміє сайт
- вибір групи, розклад на день і тиждень, поточна/наступна пара з таймером;
- робочі суботи (по колу ПН I → … → ПТ II, окремо для 1 курсу та 2–4 курсів; розпорядження мають пріоритет);
- час у поясі пристрою; тривоги зі звуком і сповіщеннями; 6 стилів, у кожного свої звуки; мікшер.

## Оновлення файлів сайту
Після змін у css/js збільште версію в `index.html` (тег `app-version` і `?v=` біля файлів) — інакше браузери
можуть узяти старі файли з кешу. Відкриті вкладки самі перезавантажаться протягом 5 хв.
